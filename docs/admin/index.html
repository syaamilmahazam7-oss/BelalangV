1. Sambungan Firebase

Nilai ini disimpan hanya dalam pelayar anda (localStorage), tidak dihantar ke mana-mana selain Firebase. Ambil dari Firebase Console → Project settings → Web app (atau dari google-services.json: current_key dan project_id).

Membaca dokumen tidak perlukan log masuk. Menyimpan perlukan log masuk dan rules Firestore yang membenarkan e-mel anda menulis (lihat docs/FIRESTORE.md).
